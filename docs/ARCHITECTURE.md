# المعمارية

Modular Monolith. التطبيق واحد، مقسّم لوحدات.

## الطبقات
1. **العرض**: React + TypeScript (`src/`). لا حسابات مالية ولا مخزنية.
2. **التطبيق**: أوامر Tauri في `src-tauri/src/commands/`، طبقة رفيعة.
3. **النطاق**: قواعد العمل والحسابات في `src-tauri/src/modules/<module>/`.
4. **البنية التحتية**: SQLx/SQLite في `src-tauri/src/database/`، والسجلات والأخطاء في `app_core/`.
5. **التكامل**: مخطط له لاحقًا (مزامنة المتجر الأونلاين عبر `sync_outbox`).

## ملاحظات
- وحدة الأساس اسمها `app_core` وليس `core` لتفادي التعارض مع حزمة `core` في Rust.
- الأخطاء ترجع للواجهة كنص عربي عبر `AppError`.
- الواجهة تتصل بـ Rust فقط عبر `src/services/api.ts`.
- صلاحيات Tauri الحالية `core:default` فقط، وتُضاف عند الحاجة.
- التطبيق يعمل بدون إنترنت. لا توجد اعتماديات شبكة وقت التشغيل.
