# التحديث من داخل التطبيق

الفحص يدوي من الإعدادات ← إعدادات متقدمة ← التحديثات. كل تحديث موقّع، والتطبيق يرفض أي ملف توقيعه لا يطابق المفتاح العام المضمّن. تُحفظ نسخة احتياطية (`pre-update`) قبل التثبيت.

## القنوات
- تجريبية: يتحدث `channel-test` مع كل push على main.
- مستقرة: يتحدث `channel-stable` عند تشغيل الـ workflow يدويًا مع تفعيل خيار stable.

## تفعيل التوقيع (مرة واحدة)
1. على جهازك: `npx tauri signer generate -w $HOME\.tauri\pos.key` ثم اكتب كلمة سر قوية.
2. انسخ المفتاح العام (محتوى `pos.key.pub`) وأرسله لتحديث `plugins.updater.pubkey` في `src-tauri/tauri.conf.json`.
3. في GitHub: Settings ← Secrets and variables ← Actions، أضف `TAURI_SIGNING_PRIVATE_KEY` (محتوى `pos.key`) و`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
4. احتفظ بنسخة من المفتاح الخاص وكلمة السر. لو ضاعا لا تعمل التحديثات للنسخ المنزّلة وتحتاج تنزيلًا يدويًا بمفتاح جديد.

بدون السر يعمل البيلد كالمعتاد بدون تحديثات (المفتاح العام الحقيقي مضبوط في الإعداد).
