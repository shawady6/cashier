# المميزات

## متاح في المرحلة 0
- واجهة عربية RTL مع وضع فاتح وداكن
- شريط تنقل لكل وحدات النظام (الصفحات غير المنفّذة تعرض رقم المرحلة)
- صفحة حالة النظام (إصدار البرنامج وSQLite وWAL والمفاتيح الأجنبية)
- إعدادات: بيانات المتجر، نوع النشاط، المخزون السالب (معطّل افتراضيًا)
- سجلات يومية في مجلد البيانات

## متاح في المرحلة 1
- تصنيفات وماركات ووحدات (مع منع التكرار بعد تطبيع الاسم العربي)
- منتجات: إضافة/تعديل/أرشفة واسترجاع (بدون حذف)، SKU، صورة، حد إعادة الطلب
- باركود متعدد لكل منتج ولكل متغير، مع منع التكرار على مستوى النظام؛ حقل الباركود يقبل الماسح USB (Enter يضيف)
- متغيرات (أحجام/عبوات) بأسعار وباركود مستقل، وتفعيلها حسب نوع النشاط
- وحدات إضافية بمعامل تحويل (كرتونة = 12 قطعة)، وكميات عشرية حسب الوحدة
- منتجات موزونة حسب نوع النشاط (وتحتاج وحدة تقبل الكسور)
- بحث بالاسم العربي/الإنجليزي (يتجاهل التشكيل واختلاف الألف والياء والتاء المربوطة) أو SKU أو الباركود، مع فلاتر التصنيف والماركة
