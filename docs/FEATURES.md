# المميزات

## متاح في المرحلة 0
- واجهة عربية RTL مع وضع فاتح وداكن
- شريط تنقل لكل وحدات النظام (الصفحات غير المنفّذة تعرض رقم المرحلة)
- صفحة حالة النظام (إصدار البرنامج وSQLite وWAL والمفاتيح الأجنبية)
- إعدادات: بيانات المتجر، نوع النشاط، المخزون السالب (معطّل افتراضيًا)
- سجلات يومية في مجلد البيانات

## متاح في المرحلة 1
- تصنيفات وماركات ووحدات (مع منع التكرار بعد تطبيع الاسم العربي)
- منتجات: إضافة/تعديل/أرشفة واسترجاع (بدون حذف)، SKU، صورة، حد إعادة الطلب
- باركود متعدد لكل منتج ولكل متغير، مع منع التكرار على مستوى النظام؛ حقل الباركود يقبل الماسح USB (Enter يضيف)
- متغيرات (أحجام/عبوات) بأسعار وباركود مستقل، وتفعيلها حسب نوع النشاط
- وحدات إضافية بمعامل تحويل (كرتونة = 12 قطعة)، وكميات عشرية حسب الوحدة
- منتجات موزونة حسب نوع النشاط (وتحتاج وحدة تقبل الكسور)
- بحث بالاسم العربي/الإنجليزي (يتجاهل التشكيل واختلاف الألف والياء والتاء المربوطة) أو SKU أو الباركود، مع فلاتر التصنيف والماركة

## متاح في المرحلة 2
- شاشة الكاشير: بحث بالاسم/SKU/الباركود، ماسح USB (يكتب ثم Enter)، سلة بكميات عشرية ووحدات بيع (كرتونة…)
- خصم على البند وعلى الفاتورة (نسبة أو مبلغ)، وضريبة شاملة قابلة للضبط
- دفع نقدي/كارت ومقسّم مع حساب الباقي. كل الأرقام تُحسب في Rust وتُعرض فقط في الواجهة
- تعليق واسترجاع الفواتير
- اختصارات: F2 بحث، F4 دفع، F8 تعليق، F9 استرجاع، Delete حذف بند، Esc إغلاق (قابلة للتخصيص من الإعدادات)
- سجل الفواتير مع تفاصيلها وبحث بالرقم والتاريخ، ومرتجعات جزئية/كاملة، وإعادة طباعة الإيصال
- إيصال 58/80 مم عبر طباعة ويندوز (أي طابعة لها تعريف في ويندوز)
- رصيد افتتاحي وتسوية مخزون يدوية، وعرض الرصيد في قائمة المنتجات
- منع نفاد المخزون افتراضيًا (قابل للتعديل من الإعدادات)، ومنع تكرار الفاتورة عند الضغط المزدوج

## المخزون والمشتريات (المرحلة 3)
- مخازن متعددة، أرصدة بمتوسط التكلفة وقيمة المخزون، سجل حركات بكل الأنواع، تنبيه نقص الأصناف
- تحويل بين المخازن، وجرد بحفظ مؤقت واعتماد يطبّق الفروق
- موردون بأرصدتهم، فواتير شراء (مسودة/استلام/إلغاء) بوحدات شراء وخصم، دفعات للمورد، مرتجعات شراء
